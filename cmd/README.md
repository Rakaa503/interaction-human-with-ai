# About AVIGO

AVIGO adalah project Artificial Intelligence yang dikembangkan untuk membangun sistem interaksi manusia dengan AI secara modular dan terstruktur.

Berbeda dari sistem chatbot sederhana yang hanya menerima input lalu menghasilkan output, AVIGO dirancang sebagai sebuah pipeline intelligence yang memiliki beberapa tahapan:

```text
User Input
    ↓
Interaction Analysis
    ↓
Context Understanding
    ↓
Decision Engine
    ↓
Response Engine
    ↓
Conversation Management
    ↓
User Response
```
